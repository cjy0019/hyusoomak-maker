Background

문제 정의와
해결 방향

금리 변동, 신규 상품 출시, 이벤트마다 현수막을 디자이너에게 의뢰하는 과정이 반복되었습니다. 빠른 시장 대응이 불가능하고 불필요한 리소스가 낭비되고 있었습니다.

AS-IS · 문제

손으로 만들고,
기다리고, 수정하고

디자이너가 Photoshop으로 매번 수작업 제작 → 검토 → 수정 → 출력까지 평균 4시간 소요. 금리 변경 시 전 영업점 현수막을 일일이 수정해야 했고, 브랜드 가이드를 준수하지 못하는 경우도 빈번했습니다.

TO-BE · 해결

입력하면
즉시 완성본 출력

상품명, 금리, 기간 등 핵심 변수만 입력하면 브랜드 가이드가 적용된 인쇄 규격 파일이 자동 생성됩니다. 마케터가 직접 운영하며, 디자이너 의뢰 없이 즉시 출력 가능합니다.

Process

어떻게 만들었나

현업 마케터 인터뷰 → 프로세스 분석 → 프로토타입 → 내부 배포까지, 실제 사용자 중심으로 설계했습니다.

01
🔍
현황 분석
기존 제작 프로세스 플로우차트 작성, 담당자 인터뷰를 통해 병목 구간과 반복 패턴 파악
02
📐
템플릿 설계
브랜드 가이드 기반 현수막 레이아웃 20종 표준화, 변수 구조 설계 및 디자인 QA
03
⚙️
자동화 구현
입력폼 → 데이터 바인딩 → 인쇄 규격 파일(PDF/PNG) 자동 렌더링 파이프라인 구축
04
🚀
사내 배포
전국 영업점 담당자 대상 가이드 문서 작성 및 교육, 피드백 반영 후 v2 고도화
